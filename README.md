## AeroSpace

Todas as janelas abrem flutuantes no workspace atual, sem tiling automático.

| Tecla | O que faz |
|---|---|
| `Alt+1…8` | Vai pro workspace |
| `Alt+Shift+1…8` | Manda a janela pro workspace |
| `Alt+Shift+R` | Recarrega a config |
