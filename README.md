## AeroSpace

| Tecla | Ação |
|---|---|
| `Alt+Q` | Layout accordion vertical |
| `Alt+W` | Layout accordion horizontal |
| `Alt+E` | Layout tiles |
| `Alt+1` … `Alt+8` | Vai para o workspace |
| `Alt+Shift+1` … `Alt+Shift+8` | Move a janela para o workspace |
| `Alt+;` | Volta para a janela anterior |
| `Alt+Shift+Space` | Alterna entre flutuante e tiling |
| `Alt+Shift+R` | Recarrega a configuração |
| `Alt+N` | Abre Notion |
| `Alt+T` | Abre WezTerm |
| `Alt+B` | Abre Bitwarden |
| `Alt+G` | Abre github.com |
| `Alt+F` | Abre Finder |
